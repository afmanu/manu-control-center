# Workspace templates

Use these only when a corresponding file is needed. Adapt headings and metadata to the personal workspace; do not fill unknown fields with invented values. Template instructions and examples are not personal facts.

- [Workspace routes](workspace.md): editable personal entry and setup progress.
- [Context](context.md): confirmed global context when no equivalent already exists.
- [Connections](connections.md): source authority, access and check evidence.
- [Source](source.md): origin, scope and captured content.
- [Project](project.md): purpose, current work, deliverables and next step.
- [Brief](brief.md): sourced work output, decisions, uncertainties and proposals.
- [Session](session.md): concise continuation when useful.

- [Interview](interview.md): answers, corrections and pause/resume.
- [Knowledge](knowledge.md): current understanding, evidence and changes.
- [Relationships](relationships.md): meaningful links and Activation Map.
- [Meeting](meeting.md): preparation/recap with decisions distinct from proposals.
- [Decision](decision.md): rationale, alternatives and review condition.
- [Scoped area](area.md): local context reusing shared guidance.
