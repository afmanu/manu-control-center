# Native schedule record

Purpose and selected workflow: actual user request and canonical skill/SOP.
Host/task ID: native identifier. Workspace and input/output routes: explicit.
Trigger/timezone: actual configured cadence. State: proposed, active, paused or removed.
Manual verification: date, useful artifact and limits.
Latest due/run: observed timestamps and host evidence, or unverified.
Latest output: artifact, evidence and meaningful change; no invented success.
Pause/stop: exact host controls and observed inactive state.
Recovery: bounded failure inspection, manual recheck and resume route.
Notification intent: preserve the user's choice without changing the work scope.
