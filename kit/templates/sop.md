# Reusable tool or workflow guide

Purpose and trigger: when this helps.
Canonical capability/source: exact skill/procedure and input routes.
Tools and access: available mechanism and limits; no credentials.
Checked: actual date and observed use, or explicitly unverified/outdated.

## Steps and output

Small repeatable steps, expected artifact location and how to reuse existing work.

## Verification and recovery

How to check useful completion, relevant failure modes and a bounded recovery/stop route. Do not claim volatile tool instructions were verified from an old note alone.

## Example and navigation

One actual or clearly synthetic example and a route from the workspace/project hub.
