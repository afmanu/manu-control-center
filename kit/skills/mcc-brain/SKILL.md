# Explore selected knowledge

Read [shared guidance](../../operating-guide.md), the workspace map and [explorer instructions](../../explorer/README.md). Reuse the requested display name and source routes. If not supplied, use the existing workspace name and the task's clearly selected note folders; ask only when the intended source scope is genuinely unknown. Never include home-wide or cross-project memory stores merely because they are accessible.

Check Node.js 22+ and use the bundled prebuilt renderer. Create a private config for the selected Markdown sources, scaffold a new local view or reuse its existing config, and launch only when requested. Preserve source notes and existing view files. Never replace a collision or stop an unrelated port owner. The viewer uses a loopback server only while open; it is optional for ordinary OS work.

Inspect graph counts, source notices and actual note reading. Verify search, category filtering, inventory and source links in the rendered view. Retain the reference globe, central orb, growth replay, Cinema and motion controls. The replay shows connectivity, not historical creation. File length, isolation or age are inspection hints, not a quality verdict; use `mcc-audit` for evidence-based assessment. Missing or ambiguous targets remain visible as limits.

Link the private view's instructions from the existing workspace route and report the local address, selected scope, actual counts, stop command and checks not exercised. Do not publish personal config, graph snapshots or notes. On no-save, explain the option without creating files or starting a server.
