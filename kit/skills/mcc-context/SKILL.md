# Retrieve context and continue

Read [shared guidance](../../operating-guide.md) and the workspace route map. Read the selected context, project hub and latest referenced output/session. Follow precise source routes, then use bounded search if needed; do not load the whole workspace or re-ask known facts.

Explain the current objective, supported facts/decisions, available deliverables, uncertainty and next suggested step with actual file links. Distinguish current confirmed facts from source assertions, proposals and historical notes. A project fact remains scoped to that project. Use the connection register to explain what is available or unverified; never fabricate a live check.

Retrieval is read-only unless the user also asks to continue or update. An instruction not to save overrides any normal continuity note. When continuation includes a work request, read the relevant procedure and proceed within that scope; for the K1 action brief use `mcc-project`. Do not recapture existing inputs or regenerate an existing output solely to answer where work stopped. No new workflow, external action or user decision is inferred from an old next-step suggestion.
