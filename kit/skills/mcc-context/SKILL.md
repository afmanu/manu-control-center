# Retrieve, learn and correct context

Read [shared guidance](../../operating-guide.md) and the workspace route map. Follow the selected canonical context, project hub and latest intended output; use bounded search when a route is incomplete. Resolve same-name notes through the project's exact path, aliases and heading, not the first search hit. A listed connection does not establish access.

## Retrieve or resurface

Answer with supported facts, decisions, available outputs, uncertainties and next suggested steps, linking actual sources. Read current statements and their dated change records before relying on old summaries. A project fact remains project-scoped. Retrieval is read-only unless continuation or an update is requested; route actual work to `mcc-project` rather than regenerating a draft just to explain where work stopped.

When asked to resurface useful knowledge, search the relevant existing knowledge/project routes for the present problem, including older material. Read candidates and explain why each helps now and any age/authority limits. Modification age does not establish whether the user has read a note, whether it is still true or whether a project is stalled. Do not promote a resurfaced hypothesis into confirmed knowledge.

## Requested interview or update

Use the [interview template](../../templates/interview.md) and [memory procedure](../../memory.md). Start only when requested, reuse answers already supplied and ask one relevant unanswered question at a time. Save in the mapped project/area context location; global interviews use the canonical context route. Resume the matching interview rather than creating another same-topic file. If starting a genuinely different interview on the same day, choose an unused filename.

Checkpoint each supplied answer before asking the next question: question/topic, answer, its status, unresolved flags, current summary and resume point. Preserve exact wording where meaning depends on it. Verify the write. On failure, keep the answer visible in chat and stop collecting more until persistence is repaired. On pause/stop, mark progress and stop asking. A no-save request instead stays in chat with no checkpoint, summary or context edit.

For an explicitly requested context update, promote only confirmed durable facts into the appropriate existing context, linking the dated answer. Plan/design brainstorming alone remains interview evidence. Apply corrections using the memory procedure; retain prior answers and meaningful changes, and inspect directly affected linked conclusions. Do not invent answers or silently resolve contradictory evidence.
