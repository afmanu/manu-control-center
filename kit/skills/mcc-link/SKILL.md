# Connect useful knowledge and routes

Read [shared guidance](../../operating-guide.md), the workspace map, selected hub and candidate targets. Limit inspection to the requested scope and relevant neighbors. Preserve existing Markdown/wikilink conventions, metadata, aliases and language. No automatic whole-vault scan, invented percentage scores, source moves or note-per-edge structure.

Separate two jobs:

- **Navigation:** when a task needs information → precise hub/path → relevant heading. Reuse an existing route when it already works. Same-name notes or aliases need explicit project-relative paths; inspect targets and headings before choosing. A missing or ambiguous target stays unresolved; ask only if it blocks the requested edit.
- **Meaning:** source → relationship → target, with a concise reason and proposed/applied status. Useful types include extends, depends on, exemplifies, contradicts, updates and questions. Use ordinary links when the type adds nothing. Shared words alone do not support an applied relationship. Keep weak links in a clearly proposed section, or omit them with a reason; do not treat them as validated edges or contaminate canonical claims.

For a requested Activation Map, use the [relationship template](../../templates/relationships.md) inside the existing hub/knowledge note when practical. Tie useful context to a real task or decision rather than drawing a decorative graph. Apply justified local linking already authorized by the request; a request to suggest links creates proposals only. Do not reopen approval for ordinary authorized edits. Private targets do not become public through linking: preserve the audience scope of both the target and the route.

Verify both directions of useful navigation: workspace entry → hub → important target, and output/knowledge note → its relevant hub. Resolve exact files, aliases and heading anchors, including existing wikilink aliases. Preserve unrelated text and avoid gratuitous backlinks on raw evidence. Report applied links, proposed/uncertain ones and any missing route. Do not claim a global audit or a live external connection.
