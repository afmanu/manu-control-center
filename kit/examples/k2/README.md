# Try the K2 knowledge and work cycle

Use the [synthetic meeting record](meeting.md) in a disposable workspace. These prompts exercise ordinary agent procedures; do not point them at personal content unless you intend that work.

1. Capture the meeting record and prepare a sourced recap. Start a Harbor context interview with a supplied project priority, save the answer and pause without further questions.
2. In a fresh session, resume the saved interview. Supply an explicit owner correction to a prior project date. Ask to update current context while retaining the earlier answer/source and preserving an accepted output.
3. Ask for a scoped synthesis and useful relationships/Activation Map. Include an older relevant note and a weak keyword-only association to check that they receive different treatment.
4. Prepare a public status draft using a chosen template. Keep private linked evidence out of the draft, including private filenames and citation routes. Preserve the accepted predecessor and make the current draft reachable from the hub.
5. Create a scoped evaluation area referencing shared guidance and canonical global context. Open a fresh session to retrieve the current date, both work outputs and the next unresolved question without duplicate capture.

For URL intake, supply a readable page and an inaccessible reference. The agent must read actual content through an available host tool, retain URL/access date and limits, and leave inaccessible content unknown. No connector is installed automatically. K2's implementation evidence and exact tested limits are recorded in the repository's development documentation.
