# Start here

## Use your AI OS

Read the [kit setup entry](kit/START-HERE.md), then ask Codex to set up a separate personal workspace or adopt a folder you select. Include the absolute destination and a first task/source if available. The agent follows [mcc-setup](kit/skills/mcc-setup/SKILL.md), reuses known context and preserves existing names, metadata and instructions.

After setup, open the personal folder for daily work. Ask to capture a source or URL, find/correct context, connect or synthesize knowledge, or prepare/continue a sourced project or meeting brief. Use your preferred language. The [synthetic example](kit/examples/README.md) provides a first task without personal information.

K2 provides six skills, shared operating guidance, templates and a dependency-free Python copy helper. Setup is complete only after personalization and route checks; the first workflow needs an actual saved result. See [current delivery status](README.md#conversion-delivery). No external connections or schedules are activated by copying files.

The complete former application stays on [archive/application-m4.1](https://github.com/afmanu/manu-control-center/tree/archive/application-m4.1); its npm commands do not apply here.
