# Inicio en una nueva sesión

Abre esta carpeta como proyecto local y pega el siguiente texto:

> Vamos a desarrollar Manu Control Center en afmanu/manu-control-center, el repositorio de GitHub elegido por Manu. Lee AGENTS.md, README.md, docs/handoff.md y docs/decisions.md; después consulta el roadmap y los contratos necesarios para la tarea actual. M0 y M1 están implementados y probados: continúa por M2.1 y construye el resolver, la planificación y la aplicación sobre los contratos y el backend de referencia existentes. Preserva la separación entre constructor, especificación e instancia, el núcleo neutral y las responsabilidades de conocimiento y ejecución. Elige y registra decisiones técnicas reversibles sin otra entrevista de descubrimiento. La primera instancia utilizable se entrega en M3. Usa los escenarios de aceptación y conserva evidencia de lo realmente probado. Trabaja en este repositorio; las carpetas anteriores son snapshots. La entrega en GitHub está autorizada; las integraciones y publicaciones en otras aplicaciones requieren su alcance correspondiente.

El prompt sirve también como entrada textual para otros entornos con acceso a los archivos. Cada entorno debe demostrar qué puede leer, escribir y ejecutar. Véase [handoff](docs/handoff.md).
