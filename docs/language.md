# Repository language and personal interaction

Maintain public repository documentation, operating instructions, skills, templates, synthetic examples, code, comments and GitHub metadata in English. Personal interaction may use Spanish or the user's preferred language.

The agent should preserve personal source wording, confirmed facts, names, paths and identifiers. Translating an explanation does not authorize translating or rewriting existing notes. Adoption respects equivalent metadata fields and existing folder conventions; report conflicting values instead of normalizing the entire workspace.

Historical Spanish source text and immutable source locators may retain their spelling for traceability. Do not copy private material into examples to illustrate localization. Use synthetic examples for language checks.

The former CLI localization and saved-plan compatibility implementation is preserved on the [application branch](https://github.com/afmanu/manu-control-center/blob/archive/application-m4.1/docs/language.md); it is not required to use the kit.
