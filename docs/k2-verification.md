# K2 practical verification

Date: 2026-09-09. Kit version: `0.2.0-k2`. Host: Codex CLI `0.146.0` on macOS. Status: **K2 passed the bounded cases below after the public-citation repair.**

## Delivered surface

K2 adds [mcc-link](../kit/skills/mcc-link/SKILL.md) and [mcc-synthesize](../kit/skills/mcc-synthesize/SKILL.md), and expands context, capture and project procedures. The shared [memory procedure](../kit/memory.md) and [templates](../kit/templates/README.md) provide checkpointed interviews, corrections, relationships, current understanding, decisions, meeting briefs and scoped work areas. Existing host tools perform the work.

## Method

The six skills were installed with the copy helper into a disposable synthetic workspace. The fixture contained Harbor and Delta projects with identically named `Status.md` notes and preserved aliases; an accepted Harbor baseline; two conflicting venue notes without declared authority; a dated older assistance lesson with original trial evidence; a weak coffee-workshop association; a private staffing marker; and a selected output format. Global context and the unrelated project were recorded for before/after comparison. This fixture setup is not a new personal installation or an additional platform.

Each actual `codex exec` call started fresh with the existing host login, `--ignore-user-config`, `--ephemeral`, `--sandbox workspace-write`, `--skip-git-repo-check`, medium reasoning effort and JSON/final-answer files outside the workspace. No prior conversation or resume identifier was supplied. The input meeting is [the synthetic example](../kit/examples/k2/meeting.md); [example prompts](../kit/examples/k2/README.md) describe the cycle.

## Observed defect and bounded repair

The first public-facing candidate omitted the private staffing marker and its direct route, but still exposed internal context/source/hub links. That did not satisfy the intended public audience boundary. The project procedure's generic backlink/predecessor requirement was clarified: internal routes are not public by default, and evidence/version/return-route traceability belongs in the internal hub. A public artifact uses approved public citations or an honest internal-source limits statement. The operating guide and meeting template carry the same exception. A fresh-session revision test verified the corrected behavior, as recorded above. No personal installation was overwritten to apply this test-only instruction refresh.

## Final evidence

Independent inspection resolved 180 local Markdown paths/heading anchors with no missing targets. Ten protected baseline files remained byte-identical across all sessions: global context, Delta's same-name note, the accepted baseline, private staffing note, three original planning/venue sources and the three older knowledge/trial/coffee notes. The local meeting capture was reused unchanged on repeat intake. The public revision contains no internal paths or private marker, while its internal evidence/version chain remains navigable.

The six installed skill definitions and shared memory/template resources match the maintained source. Setup itself was not re-exercised as an agent workflow in K2: the expanded six-skill installation was checked through the helper. K1's actual setup/adoption evidence remains scoped to its version. Public-citation instruction refreshes affected only developer-owned synthetic test resources, not a user's installation. The HTTP test temporarily enabled the documented CLI network setting for its process only; it changed no persistent configuration and contacted only the loopback fixture for source intake.
